# Laboratório Prático: Instalação e Configuração do Kali Linux no VirtualBox

## 🎯 Objetivo
Configurar um ambiente controlado para práticas de testes de segurança e análise de redes.

## 🛠️ Ferramentas Utilizadas
- Oracle VM VirtualBox
- ISO Kali Linux (64-bit)
- Comandos de terminal: `ip a`, `ping`, `nmap`

## 📝 Passo a Passo Executado
1. **Criação da Máquina Virtual:** Alocação de 2 VCPUs e 4GB de RAM no VirtualBox.
2. **Configuração de Rede:** Ajuste da interface para modo *NAT Network* para isolamento do ambiente.
3. **Instalação do SO:** Particionamento padrão e instalação dos utilitários de segurança.
4. **Verificação de Conectividade:** Teste de rotas de rede via terminal para garantir isolamento seguro.

## 🔍 Aprendizados
- Configuração de interfaces de rede virtuais.
- Princípios de isolamento de ambiente (Sandbox) para testes de segurança.
